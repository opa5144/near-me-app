# NearMe

NearMe is a mobile app that helps users discover local stores, events, and activities.  
The app plans out a personalized day for users based on their interests, preferences, budget, and available time.

### Prerequisites

- Git
- Node.js LTS
- Expo Go on a mobile device

### Setup

In a terminal:

```bash
git clone https://github.com/opa5144/near-me-app.git
cd near-me-app/mobile
npm install
npx expo start
```
